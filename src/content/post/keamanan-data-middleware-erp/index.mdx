Ketika menghubungkan sistem ERP internal perusahaan dengan platform e-commerce berbasis cloud, keamanan data bukan sekadar fitur tambahan — melainkan prasyarat mutlak. Database SAP Business One menyimpan data rahasia perusahaan: data keuangan, daftar harga grosir, margin laba, dan data pelanggan.

Di B1connect, kami menerapkan prinsip *Security by Design* dalam setiap lapisan arsitektur kami.

## 1. Enkripsi Kredensial At-Rest (AES-256-GCM)

Password login SAP Service Layer dan Access Token privat Shopify tidak pernah disimpan dalam bentuk teks biasa (*plain text*).

- Kami menggunakan algoritma **AES-256-GCM (Galois/Counter Mode)**, standar enkripsi simetris yang juga digunakan oleh lembaga keuangan dan militer.
- Mode GCM memberikan keuntungan ganda: **kerahasiaan data (confidentiality)** dan **otentikasi integritas data (authenticity)**, memastikan ciphertext tidak dapat dimanipulasi tanpa terdeteksi.

## 2. Validasi Integritas Webhook (HMAC-SHA256)

Setiap notifikasi webhook order yang dikirimkan oleh Shopify harus dipastikan benar-benar berasal dari server resmi Shopify:

- B1connect menghitung hash HMAC dari payload mentah menggunakan *Shared Secret* aplikasi.
- Verifikasi dilakukan menggunakan fungsi perbandingan waktu konstan (*constant-time comparison*) untuk mengeliminasi risiko kerentanan serangan *side-channel timing attack*.

## 3. Isolasi Data Multi-Tenant

Dalam lingkungan multi-tenant di mana satu engine melayani beberapa toko Shopify:

- Setiap tenant memiliki konfigurasi, kredensial, dan kunci enkripsi yang terisolasi secara terpisah.
- Akses data antar tenant dipisahkan di level query database untuk menjamin tidak ada kebocoran data (*data leakage*) antar merchant.

Dengan lapisan perlindungan ini, perusahaan Anda dapat memanfaatkan fleksibilitas integrasi modern tanpa mengorbankan kepatuhan standar keamanan data enterprise.
