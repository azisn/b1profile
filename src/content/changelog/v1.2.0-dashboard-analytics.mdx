## Yang Baru di v1.2.0

- **Live Event Stream**: Pantau aktivitas sinkronisasi transaksi secara real-time dengan visual status latensi sub-detik.
- **Test Connection Tool**: Uji konektivitas Service Layer dan validasi hak akses CompanyDB langsung dari wizard tanpa perlu deploy ulang.
- **Peningkatan Error Logging**: Pesan error dari SAP B1 kini disajikan dengan penjelasan ramah pengguna dan panduan troubleshooting.
- **Dukungan SAP HANA & SQL 2022**: Pengujian kompatibilitas penuh untuk SAP Business One versi 10.0 FP 2305 ke atas.
